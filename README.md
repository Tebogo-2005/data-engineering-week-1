# Data Engineering Week 1 – ETL Pipeline

## Overview
This project implements a basic ETL (Extract, Transform, Load) pipeline using Python and Pandas.

- **Extract**: Read CSV files (users and orders)
- **Transform**: Join and aggregate data to count purchases per day per gender
- **Load**: Save the result as a new CSV file

## Files
- `wtc_week1.ipynb` – Jupyter notebook containing the complete pipeline
- `output.csv` – The final transformed dataset (generated when you run the notebook)

## Requirements
- Python 3.12
- pandas

## How to Run
1. Clone the repository
2. Install pandas: `pip install pandas`
3. Run all cells in the Jupyter notebook
